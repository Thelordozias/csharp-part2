# Unit 5 – Configuring Visual Studio Code Extensions for C#

In this unit, I learned how Visual Studio Code can be extended using extensions
to support C# development.

I installed the C# Dev Kit extension published by Microsoft. This extension
provides essential features such as syntax highlighting, debugging, and project
management for C# applications.

I also learned the difference between the .NET SDK and the .NET Runtime.
The SDK is required to build and debug applications, while the runtime is
required to run them.

Installing the C# Dev Kit automatically installs related extensions such as:
- C# language support
- .NET Install Tool

This unit helped me understand how Visual Studio Code connects with the .NET
ecosystem and why extensions are critical for an efficient C# development setup.
