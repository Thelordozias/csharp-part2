# Unit 1 – VS Code basics

This unit explains the goal of the module and the C# development workflow.

Key ideas:
- Software development is a process, not just writing code
- An IDE helps manage writing, testing, debugging, and versioning code
- Visual Studio Code is a lightweight editor that supports C# using extensions

Goal of the module:
- Set up VS Code for C# development
- Install .NET
- Build and run a first C# console application
