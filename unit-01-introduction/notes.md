# Unit 1 – Introduction to C# Development Environment

In this unit, I learned that software development is not only about writing code,
but about following a structured process that includes writing, debugging, testing,
versioning, and releasing applications.

I learned what an IDE (Integrated Development Environment) is and why developers
use it to be more productive. An IDE groups multiple tools together such as a code
editor, debugger, terminal, and version control integration.
